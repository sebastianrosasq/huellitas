Los fragmentos de código se exportaron con CodeSnap desde el archivo `src/huellitas/quadtree.py`, las demás imágenes son capturas de las ventanas de VS Code y Huellitas.

Para actualizar una captura de código, selecciona el fragmento en VS Code, abre la paleta con `Ctrl+Shift+P` y ejecuta **CodeSnap**, luego usa el botón de captura para guardar el PNG en `evidencias/`.

## Entrega final

Para la entrega final hay que actualizar el informe con la versión terminada del programa. Según la indicación del profesor, debe incluir carátula, contexto, capturas del código y de la interfaz, y el enlace a un video propio de YouTube con la explicación del algoritmo y una demostración.
